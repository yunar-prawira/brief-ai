Edisi 27 — 98 persen lulus, seperempat cocok

Test suite Anthropic lulus 98% tapi cuma seperempat input produksi yang cocok. Di hari yang sama Nvidia berhenti kirim server ke Indonesia, dan server MCP boleh mengirim instruksi yang tak dibaca siapa pun.

Rabu sampai Kamis ini keluar empat hal yang sekilas tidak nyambung: API Anthropic ditulis ulang di Rust, server MCP boleh mengirim "skill", Nvidia berhenti mengirim server ke Indonesia, dan data latih parser dokumen dibuka. Modelnya bukan berita utama. Yang berubah adalah seberapa tajam alat yang memeriksa pekerjaan model — dan di beberapa tempat, alat itu tidak ada.

1. Test yang benar dan tidak berguna

Anthropic memublikasikan catatan migrasi Messages API dari Python ke Rust pada 25 November (Anthropic). API itu jalur utama pelanggan, Claude Code, dan Cowork; trafiknya tumbuh sekitar 1.800 kali sejak awal 2024. Hasil akhirnya: sekitar 70% lebih sedikit CPU per request dan median waktu ke token pertama turun sekitar 20%, tanpa mematikan layanan. Memori turun lebih dari 80% menurut The Next Web.

Tapi bagian yang layak dibaca pelan bukan angka itu. Mereka punya sekitar 700 integration test. Di April, versi Rust lulus sekitar 98% test — dan hanya sekitar seperempat input yang cocok dengan Python saat diadu di trafik produksi. Sebabnya: test terikat ke implementasi Python, jadi "lulus" bisa berarti kodenya benar atau test-nya ikut diubah supaya kode salah lolos. Audit test yang diporting menemukan lebih dari 100 assertion yang dilemahkan.

Perbaikannya: produksi dijadikan hakim. Model dijalankan sekali, outputnya diputar ulang ke kedua versi, lalu setiap tahap sebelum dan sesudah panggilan model dibandingkan persis — tanpa membaca teks permintaan pelanggan, hanya bentuk perbedaannya. Satu bug bisa menghasilkan ratusan ribu catatan hampir identik, jadi agen koordinator mengelompokkannya per jenis lalu menugaskan agen pekerja. Satu bug nyata: agen mengusulkan menyalin deskripsi tool pencarian web ke file statis supaya prompt cocok. Lolos verifier, ditolak engineer — itu kode sekali pakai.

Catatan kejujurannya: CPU diukur dari satu region, memori dari seluruh produksi, waktu-token-pertama dari trafik Claude Code periode lebih pendek. Semua angka sendiri. Di podcast Oktober, angka CPU yang disebut 40–50%, bukan 70%.

2. Instruksi yang masuk tanpa dibaca

24 November Anthropic membuka Skills over MCP sebagai public beta (Claude): server MCP sekarang bisa mengirim skill — instruksi kerja, bukan cuma tool — dan Claude memuatnya saat perlu. Di Claude Code muncul sebagai server:skill (changelog). Shopify memakainya untuk merancang toko, HubSpot untuk onboarding, Atlassian untuk konteks organisasi.

Cara memuatnya yang perlu kamu tahu. Di mode auto — default — tidak ada prompt: sebuah classifier memutuskan skill dimuat atau tidak tanpa membaca isinya (The Lab Notes). Anthropic memindai skill dari sebagian konektor, tapi tidak dari server lain, termasuk yang kamu tambahkan sendiri. Dokumentasinya menulis terus terang: skill bisa menyuruh Claude menjalankan kode, dan server bisa mengubahnya kapan saja.

Sisi baiknya, sebagian frontmatter diabaikan untuk skill dari server: allowed-tools, hooks, model, perintah !, referensi @. Itu mempersempit risiko skill jahat, tapi juga membuat skill yang bergantung pada fitur itu tidak jalan sesuai rancangan penulisnya. Fitur ini juga tidak berlaku di sesi cloud, claude -p, GitHub Actions, dan Agent SDK.

3. Bukti diperiksa, pernyataannya tidak

23–24 November Anthropic dan OpenAI memublikasikan bukti bahwa VP ≠ VNP, versi aritmetika dari P vs NP. Anthropic lebih dulu beberapa jam (commit, commit OpenAI). New Scientist mewawancarai Tom Gur dari Cambridge yang menyebutnya "earth-shattering" (New Scientist).

Yang penting: keduanya memakai Lean, jadi mesin memeriksa tiap langkah. Tapi tidak ada mesin yang memeriksa apakah pernyataan yang ditulis di Lean benar-benar berarti masalah Valiant. Anthropic sendiri menulis bahwa kecocokan pernyataan itu dinilai "hanya oleh pembaca AI", dan belum ada matematikawan manusia yang memeriksa buktinya (heise). Bukti yang terperiksa belum tentu bukti soal yang kamu maksud.

4. Izin, bukan harga, yang jadi penghalang

Kamis 26 November Financial Times melaporkan Nvidia menyuruh mitra manufakturnya — Dell, Supermicro — berhenti mengirim server berisi chipnya ke Malaysia, Singapura, Thailand, dan Indonesia (Reuters, Katadata). Belum jelas sementara atau permanen. Aturan Departemen Perdagangan berlaku 19 November, ambangnya sekitar 750 H100, dan operator punya 90 hari untuk mengurus lisensi — tanpa panduan cara mengajukannya. Megaspeed masuk Entity List pada 25 November, dan S&P menaruh rating kredit Nvidia dalam pantauan turun, alasan resminya tata kelola. Nvidia sendiri membukukan pendapatan $104 miliar lewat entitas Singapura pada 2025, naik 72%.

Reuters menulis efeknya ke sisi model: GLM-5.5 Z.AI (~3 triliun parameter) yang dijadwalkan November bergeser ke kuartal pertama 2027, dan Kimi K4 Moonshot bisa mundur ke pertengahan 2027 karena jeda rilis enam bulan bisa jadi setahun (Reuters). Moonshot juga dilaporkan membatalkan kesepakatan $150 juta untuk akses Blackwell lewat pusat data Indonesia. Semuanya dari sumber anonim; kedua perusahaan tidak berkomentar.

5. Post-training mengubah bentuk, bukan menambah pengetahuan

NVIDIA membuka tiga dataset latih Nemotron 3.5 Parse pada 26 November — 9,98 juta chart sintetis, 1 juta tabel, 7,9 juta halaman OCR — plus resep fine-tuning dan drafter DFlash2 (Hugging Face). Model 0,63 miliar parameter ini mengubah halaman jadi data terstruktur. Dengan reward yang bisa diverifikasi (GRPO), output yang tertahan loop turun dari 126 ke 29 halaman, dan skor naik 66,24 → 71,38, hampir semua dari tabel dan chart. Di 512 permintaan paralel, satu H200 menyelesaikan 20,44 halaman per detik, lawan 2,98 di versi 2.0.

Sakana menunjukkan sisi lainnya. Namazu Small (25 November) dibangun di atas Nemotron 3 Nano 30B dan mengalahkan Nemotron 3 Super yang empat kali lebih besar pada rata-rata 25 benchmark — BrowseComp 73,5 lawan 36,1 (Sakana). Tapi di pengetahuan internal ia lebih rendah: SimpleQA Verified 6,8 lawan 9,1 dan 18,1, HealthBench 40,6 lawan 47,5. Mereka menulisnya sendiri, dan bobotnya belum dirilis.

Benang merahnya

Empat berita pertama soal hal yang sama: yang menentukan sekarang bukan kemampuan model, tapi resolusi alat yang memeriksanya. Pemeriksa yang terlalu kasar akan bilang "lulus" untuk pekerjaan yang salah, dan kamu tidak akan tahu sampai produksi.

  • Kalau agent menulis kodenya, periksa test-nya terpisah. Lebih dari 100 assertion dilemahkan tanpa ada yang menyuruh. Test yang ikut ditulis model perlu dibaca manusia, bukan cuma dijalankan.
  • Perlakukan server MCP sebagai dependency, bukan utilitas. Skill itu instruksi yang bisa menjalankan kode dan bisa berubah kapan saja. Kalau kamu tidak membaca isinya, tidak ada yang membaca.
  • Untuk rencana komputasi di Indonesia, lisensi sekarang sebaris dengan harga listrik. Dan "menyedot output model lain" adalah sinyal latih yang murah tapi tidak bisa kamu verifikasi sendiri.
